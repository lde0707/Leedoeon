01 — TREND INSIGHT

왜 지금, '레디코어'인가

서울대 소비트렌드분석센터(김난도 외)가 발표한 《트렌드 코리아 2026》은 불확실성이 커질수록 오히려 '철저한 사전 준비'가 삶의 태도가 되는 현상을 레디코어(Ready Core)로 정의합니다.

노션 템플릿으로 하루를 설계하고, 엑셀로 예산을 짜고, 여행 전 동선을 분 단위로 계획하는 것 — 젊은 세대에게 '준비'는 더 이상 피곤한 일이 아니라 불안한 시대를 통제하는 가장 확실한 방법이자 하나의 놀이·자기표현이 되었습니다.

2026년 10대 키워드 전체 (레디코어 강조)

휴먼 인 더 루프 필코노미 제로 클릭 ★ 레디코어 AX 조직 픽셀 라이프 프라이스 디코딩 건강지능 HQ 1.5가구 근본니즘
02 — GAME FIT

트렌드 × 게임, 두 개의 '준비 루프'

이동 요새 디펜스의 핵심 재미는 웨이브가 도달하기 전, 실버·골드·플래티넘 증강을 조합해 '나만의 방어 설계도'를 짜는 데 있습니다. 이는 레디코어 트렌드가 말하는 준비 문화를 게임 메커닉으로 이미 구현하고 있다는 뜻입니다.

레디코어 트렌드 특징이동 요새 디펜스 대응 요소
불확실한 미래 → 사전 계획으로 통제감 확보웨이브 도달 전 증강 트리 설계 → 준비된 만큼 방어 성공률 상승
노션 · 엑셀로 짜는 '완벽한 하루'도언이 실제 엑셀 밸런싱으로 설계한 증강 조합표와 동일한 성취감 구조
준비 과정 자체를 콘텐츠 · 자기표현으로 소비내 설계도를 캡처·공유하는 UGC로 자연 전환 가능
등급별로 '얼마나 준비됐는지' 과시 (레디니스)실버 · 골드 · 플래티넘 등급 체계와 1:1 매칭
03 — EVENT DESIGN

이벤트 구성 : 2개 트랙

"완벽한 준비"를 보여주는 트랙과 증명하는 트랙으로 나눠, 창작형 유저와 경쟁형 유저를 모두 끌어들입니다.

Track A · 공유형

출격 설계도 공모전

내가 가장 자신 있는 증강 빌드를 '설계도 카드'로 캡처해 커뮤니티에 공유. 창의성 · 효율성 기준으로 인기 투표를 진행합니다.

  • 참여 방식: 인게임 빌드 요약 카드 자동 생성 → SNS/커뮤니티 업로드
  • 심사: 유저 투표 60% + 운영진 밸런스 심사 40%
  • 노림수: 레디코어=자기표현이라는 트렌드 축을 그대로 UGC로 전환
Track B · 경쟁형

레디 웨이브 챌린지

지정 웨이브(예: 20웨이브)까지 '최소 피해'로 도달한 준비된 설계도만 랭킹에 오르는 효율 경쟁전입니다.

  • 참여 방식: 챌린지 전용 시드로 플레이 → 결과 자동 집계
  • 지표: 요새 잔여 체력 > 클리어 타임 > 사용 증강 수(적을수록 가점)
  • 노림수: '준비 = 실력'이라는 레디코어의 승부욕 코드를 자극
04 — SCHEDULE

진행 일정 : 4개의 웨이브

디펜스 게임의 웨이브 구조를 그대로 이벤트 타임라인에 적용해, 마지막 '보스 웨이브'를 시상식으로 연결합니다.
