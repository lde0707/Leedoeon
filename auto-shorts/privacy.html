1. 개요

auto-shorts(이하 "앱")는 이도언(이하 "운영자")이 본인의 YouTube 채널 운영을 위해 만든 개인 자동화 도구입니다. 이 앱은 운영자 본인의 Google 계정에만 연결되며, 다른 사람의 Google 계정 정보를 수집하거나 이용하지 않습니다.

2. 접근하는 Google 사용자 데이터

  • Google Drive: 앱이 생성한 파일(영상, 대본, 음성, 검수 기록)을 만들고 관리합니다.
  • Google Sheets: 운영자의 관리 시트에서 주제 목록, 생성 상태, 승인 기록을 읽고 씁니다.
  • YouTube: 운영자 본인의 채널에 운영자가 승인한 영상을 업로드합니다.

3. 데이터 이용 목적

위 데이터는 영상 제작 파이프라인을 실행하고 결과물을 보관·업로드하는 목적으로만 이용됩니다. 광고, 판매, 프로파일링 또는 AI 모델 학습에 이용하지 않습니다.

4. 데이터 보관과 공유

  • 생성된 파일과 기록은 운영자의 Google Drive와 Google Sheets에 보관됩니다.
  • Google 사용자 데이터는 제3자에게 판매하거나 공유하지 않습니다.
  • 대본 작성과 검수를 위해 영상 주제와 공개 웹 자료를 외부 AI API(Anthropic, Google Gemini)로 보냅니다. 이때 Google Drive·Sheets·YouTube 계정 데이터는 보내지 않습니다.
  • 인증 정보(OAuth 토큰, API 키)는 운영자가 관리하는 비공개 저장소의 암호화된 비밀 값으로만 보관합니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 접근 권한 철회와 삭제

운영자는 Google 계정 권한 페이지에서 언제든지 앱의 접근 권한을 철회할 수 있으며, Drive와 Sheets에 저장된 파일은 직접 삭제할 수 있습니다.
