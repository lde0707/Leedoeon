기준일: 2026.11.12
Unity 6000.3.10f1 / 최신 Windows 빌드의 별도 복사본 / 1920×1080 / 24fps / 무음
원본 프로젝트·씬·출시용 빌드 수정 없음. 복사본에 캡처 전용 실행기를 연결하여 RenderTexture로 실제 런타임 화면을 녹화함.
타이틀·첫 이야기·F0·1A·1B 장면을 편집해 연결함. 방·시점을 준비하고 게임 조작 API를 호출했으므로 연속 수동 플레이, 입력 회귀 전체, 성능 측정 결과로 보지 않음.
F0: 덮개·다리·두 반사면의 조작 후 광로 연결, 걸쇠 확정과 Solved 상태 확인.
1A: 여우 기록 뒤 토끼 기록, 두 그림자 완료 상태 확인.
1B: 충전·잠금·운반·기록대 방출·창 복구·재충전·출구 방출과 완료 상태 확인.
현재 포트폴리오의 테스트 케이스는 별도의 설계안이며 전체 절차를 수행한 PASS로 집계하지 않음.
기존 1A 음수 스케일 BoxCollider 경고는 원본 빌드 로그에서도 남아 있음. 이번 미디어 갱신에서 수정하지 않음.
