auto-shorts.

Personal automation tool that produces short game-tips videos ("게임 속 숨은 비밀") and uploads them to the Operator's own YouTube channel. The Operator researches, writes and fact-checks each script; the pipeline renders and uploads it.

게임 속 숨은 장치와 꿀팁을 알려주는 YouTube Shorts를 만들어 운영자 본인 채널에 올리는 개인 자동화 도구입니다. 대본은 운영자가 조사·작성·검수하고, 파이프라인이 렌더링과 업로드를 맡습니다.

Uses YouTube API Services · Privacy Policy · Terms

How it works

  1. The Operator researches a topic and writes a fact-checked script (title, description, tags, scenes, sources). · 운영자가 주제를 조사하고 검수한 대본을 저장소에 올립니다.
  2. GitHub Actions renders original 3D clips in Blender and composes the vertical video with captions and Google Cloud Text-to-Speech narration. · Blender 3D 클립 렌더링, 자막·TTS 합성.
  3. The Operator starts the run and chooses the privacy status (public / unlisted / private). · 실행할 때 운영자가 공개 범위를 직접 고릅니다.
  4. The video is uploaded to the Operator's own channel with the YouTube Data API (videos.insert), marked "not made for kids" and "contains altered or synthetic content". · 운영자 본인 채널에 업로드, 아동용 아님·AI 생성 표시.

Google account access

UsersOne user only: the Operator. No other person's Google account is accessed. · 운영자 한 명만 사용합니다.
YouTubeScope youtube.upload: upload videos and set their metadata on the Operator's channel. Nothing is read from YouTube. · 업로드만 하며 YouTube에서 데이터를 읽지 않습니다.
CredentialsOAuth refresh token stored encrypted in Google Cloud Secret Manager; never logged. · 토큰은 Secret Manager에 암호화 보관.
