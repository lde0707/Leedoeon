Privacy Policy

Effective date: November 13, 2026 · 시행일: 2026년 11월 13일

1. Overview

auto-shorts ("the App") is a personal automation tool built and operated by Doeon Lee ("the Operator") to publish the Operator's own YouTube Shorts on the Operator's own channel. The App uses YouTube API Services. It connects only to the Operator's own Google account and does not collect or use any other person's Google account data.

auto-shorts(이하 "앱")는 이도언(이하 "운영자")이 본인 채널에 본인이 만든 YouTube Shorts를 올리기 위해 만든 개인 자동화 도구입니다. 앱은 YouTube API 서비스를 사용하며, 운영자 본인의 Google 계정에만 연결됩니다. 다른 사람의 Google 계정 데이터는 수집하거나 이용하지 않습니다.

2. YouTube Terms and Google Privacy Policy

By using the App, users agree to be bound by the YouTube Terms of Service. Data accessed through YouTube API Services is also handled under the Google Privacy Policy.

앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. YouTube API 서비스를 통해 다루는 데이터에는 Google 개인정보처리방침도 적용됩니다.

3. What data the App accesses

  • YouTube (scope: youtube.upload): the App uploads videos and sets their metadata (title, description, tags, category, privacy status, made-for-kids and altered/synthetic content declarations) on the Operator's own channel.
  • The App does not read viewers' data, comments, subscribers, analytics, or any other channel's information.

YouTube(권한: youtube.upload) — 운영자 본인 채널에 영상을 올리고 제목·설명·태그·카테고리·공개 범위·아동용 여부·AI 생성 표시를 설정합니다. 시청자 정보, 댓글, 구독자, 통계, 다른 채널 정보는 읽지 않습니다.

4. How the data is used

Data is used only to upload the Operator's videos. It is not used for advertising, sale, profiling, or training AI models.

데이터는 운영자의 영상을 올리는 데에만 쓰며, 광고·판매·프로파일링·AI 학습에 쓰지 않습니다.

5. Storage and sharing

  • The only stored credential is the OAuth refresh token for the Operator's channel. It is kept encrypted in Google Cloud Secret Manager in the Operator's project, is never printed to logs, and older versions are destroyed when it is replaced.
  • The App does not store any YouTube API data beyond the ID of each uploaded video, which is shown in the run log.
  • Google user data is never sold or shared with third parties.
  • Voice-over is generated with Google Cloud Text-to-Speech from the Operator's own script text. No Google account or YouTube data is sent to it.

저장하는 인증 정보는 운영자 채널의 OAuth refresh token 하나뿐이며, 운영자 프로젝트의 Google Cloud Secret Manager에 암호화해 보관하고 로그에 출력하지 않습니다. 업로드된 영상 ID 외에 YouTube API 데이터는 저장하지 않습니다. Google 사용자 데이터는 판매하거나 제3자와 공유하지 않습니다. 음성은 운영자가 쓴 대본으로 Google Cloud TTS에서 만들며, 계정·YouTube 데이터는 보내지 않습니다.

6. Limited Use

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

앱의 Google API 정보 사용과 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

7. Revoking access and deleting data

Access can be revoked at any time at the Google security settings page. After revocation the stored token stops working, and the Operator destroys it in Secret Manager. Uploaded videos can be deleted in YouTube Studio.

Google 보안 설정 페이지에서 언제든 앱의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 작동하지 않으며 운영자가 Secret Manager에서 폐기합니다. 올라간 영상은 YouTube 스튜디오에서 삭제할 수 있습니다.

8. Changes

Changes to this policy are posted on this page with a new effective date.

방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다.
