GW-R01 | 화면 전환 확인 | 비회원 동의 후 새 지도 진입
사전 조건: 비회원 로그인 화면에서 시작한다.
절차: 비회원 로그인 → 모두 동의 → 동의합니다를 누른다.
기대: 선택한 동의 상태가 표시되고 최신 지도 화면으로 이동한다.
관찰: 전체 동의와 버튼이 초록색으로 바뀌고, 새 지도 프레임 406-1078로 이동했다.
화면: assets/greenway/20261112/consent.png

GW-R02 | 화면 전환 확인 | 선택한 목적지와 경로 정보의 일치
사전 조건: 새 지도에서 목적지 찾기를 연다.
절차: 목적지 목록의 신림역을 선택하고 목록·상세의 장소명, 시간, 거리를 비교한다.
기대: 선택한 장소명과 시간·거리가 상세 화면에서도 일치하고 경로선이 보인다.
관찰: 신림역 목록과 상세에 12분·850m가 동일하게 표시됐다. 상세 프레임 406-1082에서 초록색 경로선과 안내 시작 버튼을 확인했다.
화면: assets/greenway/20261112/route.png

GW-R03 | 화면 전환 확인 | 길안내에서 도착·리포트까지 이어지는 흐름
사전 조건: 신림역 경로 상세 화면에서 시작한다.
절차: 안내 시작 → 도착 확인 → 이동 리포트 보기를 차례로 누른다.
기대: 안내 중 상태, 도착 화면, 이동 리포트로 순서대로 이어진다.
관찰: 406-1088 → 406-1108 → 406-1096으로 이동했다. 안내 화면의 120m 앞 우회전 문구와 도착 화면의 리포트 진입 버튼을 확인했다. 실제 위치 도착 판정과 기록 계산은 검증하지 않았다.
화면: assets/greenway/20261112/arrival.png

GW-R04 | 화면 전환 확인 | 하단 탭 전환과 지도 복귀
사전 조건: 이동 리포트 화면에서 시작한다.
절차: 저장 → 내 정보 → 설정 → 지도 탭을 누른다.
기대: 탭에 대응하는 화면으로 이동하고 마지막에 지도로 돌아온다.
관찰: 저장 406-1094, 내 정보 406-1098, 설정 406-1100을 거쳐 지도 406-1078로 돌아왔다. 각 화면에서 선택된 탭 표시를 확인했다.
